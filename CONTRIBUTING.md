# Contributing to TemplateAPI

Thanks for considering a contribution.

## Development setup

1. Fork the repository and create a branch from `master`.
2. Install dependencies with `npm install`.
3. Run `npm test` and `npm run build` before opening a pull request.
4. Keep each pull request focused on one change.

## Good contributions

Useful contributions include:
- fixes to generated TypeScript or JavaScript projects;
- new optional modules or templates;
- CLI usability improvements;
- tests and reproducible bug reports;
- documentation and examples;
- security hardening that does not break the generated API contract.

## Pull requests

Describe the problem, the approach, and how you tested it. If the change affects generated output, include a small before/after example.

By contributing, you agree that your contribution is licensed under the repository's MIT license.
